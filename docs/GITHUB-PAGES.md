# Public research report on GitHub Pages

The project website is https://ebergel.github.io/ai-behavior-lab/ .

Its source is `docs/reviewer-milestone-20261022/index.html`, with downloadable figure data in the same directory. The report is a dated research milestone, not a live dashboard. It works without the local Python server or API keys.

`.github/workflows/research-pages.yml` publishes only that report directory using GitHub Pages. It runs when the report or workflow changes on `main`, and can also be dispatched manually. The complete research archive remains available in the repository but is not copied into the website deployment.

The report was originally prepared with Sites. The researcher explicitly requested GitHub Pages hosting on 23 October 2026. This is the public project website; the earlier owner-private Sites copy is independent and its access policy is unchanged.

Comments can be copied/downloaded or submitted by the reviewer as a GitHub issue. The page never sends comments automatically. Updating the public report does not change the original experimental evidence.
