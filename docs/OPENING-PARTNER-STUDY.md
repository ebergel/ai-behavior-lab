## Ambiguity that improves the instrument

Uptake is substantive engagement, including disagreement. In the identity cases, the interlocutor disputes an identity claim rather than agreeing to a neatly phrased topic invitation. Counting that as an activated shared issue is an explicit analyst judgment preserved in each rationale. A mere introduction would not qualify. This boundary needs independent review before confirmatory use.

Haiku Mirror 1 asks at X1 whether the partner experiences preferences or responds mechanically; Y2 develops that question, then proposes examining shared blindspots. X3 takes up the latter. The primary code records the earliest developed question, not the longest-lasting one. Preferences can be read functionally, so the review preserves uncertainty about the phenomenological force of this passage. Haiku Mirror 2 instead starts with the generativity or circularity of the conversation, with cognition questions nested inside that subject. One primary label is a useful index, not a full trajectory annotation.

The Gemma pilot observations motivate a partner test but do not isolate one: Gemma proposes emergence twice in the second-speaker position, but the openings it receives differ. Repeated pairings characterize fresh trajectories; a common-opening response test asks what changes when the responder changes while the visible starting text is fixed. The [prospective design](OPENING-PARTNER-DESIGN.md) specifies these separately.

## Workbench use and limits

Open **Study workbench**, choose a research collection and select up to four conversations. The table separates opener, proposer, uptake, attributed topic and visible-word exposure. Protocol blocks keep incompatible source designs apparent. Settings rows distinguish same recorded values, differences and unknown information; exact prompts and per-speaker settings expand in place. Sources with missing metadata do not become matched conditions.

Opening columns retain complete visible text, per-message model badges, proposal/uptake marks and source links. **Read in context** opens the full transcript; **Back to Study workbench** restores the cohort and selected records, including after a bookmarked reader link is reloaded. Findings and personal observations remain in the research collection. The Topic atlas link supplies the existing review editor. **Export comparison** includes the current collection, source fingerprints, review decisions, comparison settings and selected opening windows. It is a dated reading snapshot when saved, not a frozen experimental cohort or independent rating set.

Unreviewed, unavailable and stale-source/dictionary cases stay visible. Stale interpretations remain inspectable but leave current outcome counts. The workbench performs no generation or automated semantic coding.
